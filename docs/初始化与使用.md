# 初始化与使用

源码：https://github.com/IMAiCool/exam

## 支持范围

| 系统 | 独立原生运行 | Docker Compose |
| --- | --- | --- |
| Windows x64 | 已在本机验证；使用完整运行包 | 支持 Linux 容器，CI 检查见 Actions |
| Windows ARM64 | 尚未提供原生运行包 | 取决于 Docker 对镜像架构的支持 |
| Linux x64 | 暂未提供完整原生运行包 | 提供部署配置，查看 Actions 实际结果 |
| Linux ARM64 | 暂未提供完整原生运行包 | 尚未验收，不应当作已验证平台 |
| macOS Intel / Apple Silicon | 暂未实现原生 Java 安全隔离，不支持完整原生判题 | 需 Docker Desktop；ARM64 镜像兼容性尚未验收 |

浏览器端可在 Windows、macOS、Linux、iPad、Android 访问服务，不需要安装判题环境。服务器包与浏览器支持是两回事。

## Windows x64 独立运行

完整运行包包含 `runtime/node`、`runtime/python`、`runtime/jdk8`、`runtime/mysql`。GitHub 自动生成的 Source code 压缩包仅包含源码，**不包含 runtime**，不能直接双击启动。

将完整包解压到自己可写的目录，在 PowerShell 中进入该目录，首次创建管理员：

```powershell
.\runtime\node\node.exe selfhost/account.mjs admin administrator --password
.\start.cmd
```

登录 http://127.0.0.1:8787/login 。管理员创建教师，教师或管理员创建学生。也可以在服务器终端创建账号：

```powershell
.\runtime\node\node.exe selfhost/account.mjs teacher teacher01 --password
.\runtime\node\node.exe selfhost/account.mjs student student01 --password
.\runtime\node\node.exe scripts/check-judge.mjs
```

`--password` 会交互式隐藏输入密码；省略则随机生成并在终端显示一次。没有固定默认密码。管理员只能通过服务器命令管理。

当前终端服务使用 Ctrl+C 停止。程序沿用 `selfhost/data`，不自动清空。向其他电脑提供访问时，应配置 HTTPS 反向代理，勿将学生运行环境直接暴露到公网。

### 维护者从源码构建 Windows 包

构建机需要 Node 24/26、Python 3.12 x64、JDK 8 x64、MySQL 8.4 x64；这些仅供构建，最终用户无需安装。依赖安装阶段需要网络。

```powershell
git clone https://github.com/IMAiCool/exam.git
cd exam
.\scripts\build-portable.ps1 -PythonHome 'C:\构建工具\Python312' -JavaHome 'C:\构建工具\jdk8' -MySQLHome 'C:\构建工具\mysql84'
.\runtime\node\node.exe scripts/check-judge.mjs
```

复制整个项目及 runtime 给目标 Windows x64 机器，排除 `.git`、`.env`、`selfhost/data`、账号密码文件和个人测试报告。运行时版本与第三方许可需随包保留；重新分发前核对第三方许可证要求。

## Linux、macOS、Windows：Docker 初始化

宿主机准备 Docker Engine/Desktop 和 Compose v2。Windows/macOS 需启用 Linux 容器。以下命令在 Linux/macOS 终端或 Windows PowerShell 执行：

```sh
git clone https://github.com/IMAiCool/exam.git
cd exam
```

Linux/macOS 复制配置：

```sh
cp .env.example .env
```

Windows PowerShell 复制配置：

```powershell
Copy-Item .env.example .env
```

首次构建并启动：

```sh
docker compose up -d --build
docker compose ps
docker compose exec exam node selfhost/account.mjs admin administrator --password
docker compose exec exam node scripts/check-judge.mjs
```

访问 http://127.0.0.1:8787/login 。无默认账号。四种可执行语言自检应全部通过，之后再投入考试。首次构建可能较慢；用 `docker compose logs --tail=100` 排查。容器启动失败不能视为平台验收通过。

本地 HTTP 使用 COOKIE_SECURE=0；生产 HTTPS 设置 COOKIE_SECURE=1，配置域名、证书和反向代理后重建服务。默认端口仅绑定宿主机回环地址。

```sh
docker compose stop
docker compose start
docker compose down
```

`down` 保留命名数据卷；不要使用 `down -v`，否则会删除数据卷。源码更新前备份数据，更新后运行四语言自检。

## 功能、数据和验证

- 可执行判题语言：Python、JavaScript、Java 8、SQL/MySQL；HTML/CSS/JSON 目前仅编辑。
- AI 功能需在 `.env` 中填写 DEEPSEEK_API_KEY，且需要网络。普通答题和本地判题无需调用 AI。
- 原生数据：selfhost/data；容器数据：exam-data 命名卷。账号数据库、试卷和归档不随源码发布。
- 至少先用教师、学生各一个账号完成发布、作答、判题、交卷、教师确认成绩的流程，再用于正式考试。
- 2 核 2GB 不适合同时重负载运行所有判题组件；资源限制不是容量保证。

当前版本的 Windows 本机回归与 GitHub Actions 验收范围分别记录，不能用源码检查代替其他平台实测。
